# For My Jaan ❤️ — a romantic apology website

Four files, no images, no installs: `index.html`, `style.css`, `script.js`, `README.md`.

## Test on your computer
1. Keep all four files in the same folder.
2. Double-click `index.html`. It opens in your browser. (Fonts load if you are online; otherwise elegant system fonts are used.)
3. Click through all six screens, collect the 5 hearts, open the envelope, and try "Phir se shuru".

## Publish free with GitHub Pages
1. Sign in at github.com (create a free account if needed).
2. Click **+** (top right) → **New repository**.
3. Name it `for-my-jaan`. Choose **Public**. Click **Create repository**.
4. Click **uploading an existing file**, drag in all four files (directly in the root, not inside a folder), then **Commit changes**.
5. Open the repository's **Settings** → **Pages**.
6. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch **main**, folder **/ (root)**, then **Save**.
7. Wait 1–3 minutes and refresh the Pages screen. A "Your site is live at…" link appears.
8. Your link will look like `https://YOUR-USERNAME.github.io/for-my-jaan/`. Replace `YOUR-USERNAME` with your real GitHub username. The site is only live once GitHub shows that message.
9. Open the link on your phone and test everything.
10. Send the link on WhatsApp.

## Set up the Share button (optional)
Open `script.js` and replace `PASTE_YOUR_PUBLISHED_LINK_HERE` in the `SITE_URL` line with your real link. The site works fine without this. Only the Share button needs it.

## Edit later
On GitHub, open the file → click the pencil icon → edit → **Commit changes**. The site updates in 1–2 minutes (hard-refresh your browser if you don't see changes).

## Tip
All the writing is in `index.html`; change any line to make it more "you".
